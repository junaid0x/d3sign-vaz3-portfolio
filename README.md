# Design Vaze Portfolio

A modern and responsive portfolio website built to showcase projects, skills, and services with a clean user experience. The website focuses on performance, responsive design, and smooth animations to create a professional online presence.

## ✨ Features

- Modern responsive design
- Interactive project showcase
- Smooth animations and transitions
- Services section
- Contact section
- Mobile-friendly layout
- Optimised performance

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/junaid0x/d3sign-vaz3-portfolio.git
```

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm run dev
```
